Product Catalog Application
This is a simple Product Catalog Application built using React.js and TypeScript. The app allows users to browse products, add items to the shopping cart, filter items by category, and sort them by price. It integrates with a mock API to fetch product data, provides a user-friendly interface, and includes basic testing using React Testing Library.

Features
Core Features:
Home Page: Displays a list of products with details like image, name, price, and category.

Shopping Cart Page: Lists products added to the shopping cart.

Add to Cart: Allows users to add items to the cart.

Remove from Cart: Allows users to remove items from the cart.

Total Price Calculation: Calculates the total price of all products in the cart.

Clear Cart: A button to remove all products from the cart.

Filter by Category: Users can filter products by category.

Sort by Price: Users can sort products by price (ascending or descending).

Technical Implementation:
Fetching Data: Product data is fetched from the public mock API: https://fakestoreapi.com/.

TypeScript Usage: Properly using TypeScript to define types for components and props.

Base Layout: A base layout with header, footer, and main content has been implemented.

Complex Components: More complex components (such as buttons, cards, and tables) have been created and reused throughout the app.

Routing: React Router has been used for navigation between the home page and shopping cart page.

Responsive Design: The application is mobile-friendly and adapts well to different screen sizes.

User Interface: The app has a clean and user-friendly UI for smooth interaction.

Testing: Basic unit tests have been implemented using React Testing Library.

Git Version Control: The project has been managed using Git, with clear commit history and a separate development branch.

Bonus Features:
Mobile Responsiveness: The app adjusts well to different screen sizes, including mobile.
